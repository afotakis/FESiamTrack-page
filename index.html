Paper

Abstract

In this paper modifications to the pipeline of the first data-driven model based feature tracker for event cameras, are proposed, that improve robustness and accuracy under domain shift. Specifically, the replacement of the separate Feature Pyramid Networks (FPN) for the event and frame branches, with a shared-weight Siamese architecture that learns a common multi-scale descriptor for both modalities, resulting in tighter cross modal alignment in a shared feature space and drastically reducing redundant parameters. Furthermore, a RAFT-style loss is adopted to supervise intermediate displacement predictions and promote more stable optimization. Experimental results show that the proposed method generalizes effectively across datasets and achieves a significant improvement over the initial zero-shot transfer performance from synthetic to real data on the established event-based feature tracking benchmark.

Motivation

Current learning-based event-frame trackers typically encode the reference frame and event data using separate networks. This introduces redundant parameters and does not explicitly constrain both modalities to produce compatible features.

Contributions

  • The replacement of the separate encoders with a shared-weight Siamese FPN for aligned event-frame feature extraction.
  • A RAFT-style loss supervising all intermediate tracking updates for improving robustness under synthetic-to-real domain shift.

Benefits

The proposed model:

  • reduces the parameters from approximately 35M to 20M,
  • significantly lowers GPU memory,
  • maintains comparable FPS, latency and FLOPs, and
  • improves performance.
Method

System Architecture

Method Overview

  • For each initialized feature, a reference patch is extracted from the initial frame and kept fixed throughout tracking.
  • At every tracking step:
  • Events are cropped around the current feature estimate.
  • Frame and event inputs pass through modality-specific stems.
  • A shared FPE extracts multi-scale descriptors.
  • The frame descriptor is correlated with the event feature map.
  • A ConvLSTM and Frame Attention Module refine the match.
  • The network predicts the next incremental displacement.
  • The feature position is updated according to:
\[ \hat{\mathbf{x}}_{f_l}(t_j) = \hat{\mathbf{x}}_{f_l}(t_{j-1}) + \Delta\hat{\mathbf{x}}_{f_l}(t_j) \]
  • The updated position determines the event search region for the next step.

Conclusion

Robust synthetic-to-real event-frame tracking

  • The proposed Siamese FPN improves synthetic-to-real generalization by sharing the multi-scale encoder between frame and event branches.
  • Although the RAFT-style loss provides little benefit on MultiFlow, it consistently improves performance on the real EDS and EC datasets by supervising the full unrolled sequence.
  • These results show that shared event-frame encoding and sequence-level supervision enable more robust real-world feature tracking.
